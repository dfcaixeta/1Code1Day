## 📌 Síntese
Esse código é um gerador de tabuadas personalizadas. Ele:

- Solicita ao usuário um número e até qual valor deseja calcular.
- Usa um laço `for` com a função `range` para percorrer os valores de 1 até o limite informado.
- Exibe cada multiplicação no formato de Tabuada.
- Finaliza com uma mensagem de encerramento.
