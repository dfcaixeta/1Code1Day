## 📌 Síntese do código

Esse código é um *gerado de tabuada* que:

- Pede ao usuário um número inteiro.
- Usa uma _list comprehension_ (Lista compreensiva) com for e range() para imprimir a tabuada de 1 a 10.
- Finaliza com uma mensagem de encerramento.

⚡ Observação Importante

- A versão com _list comprehension_ funciona, mas é considerada um uso não convencional.
- Normalmente, seria mais claro usar um for tradicional.
