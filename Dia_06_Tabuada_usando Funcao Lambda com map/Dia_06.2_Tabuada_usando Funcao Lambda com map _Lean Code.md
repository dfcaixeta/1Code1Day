# 📌 Síntese do código

Essa versão:

  - Solicita ao usuário um número.
  - Usa _map_ + _lambda_ para imprimir diretamente cada multiplicação de 1 a 10 definida na função _range()_.
  - Finaliza com uma mensagem de encerramento.

➡️ É uma forma minimalista e funcional de escrever a tabuada, aproveitando recursos do Python para reduzir código sem perder clareza.

⚡ Observações importantes - Comparações entre as versões:

  - Eliminação da lista table:
    - Em vez de armazenar os resultados em uma lista, usamos map diretamente para aplicar o _print()_ em cada valor do _range()_.

  - Uso de _f-strings_:
    - A saída fica mais clara e elegante.

  - Mais conciso:
    - O código gera a tabuada em uma única linha de lógica, sem precisar de variáveis auxiliares.
